STRUCTURE ANALYSIS

-Functional Dependencies
one column decides the value in another column
Customer ID → Name : Each unique Customer ID determines exactly one Name.
(Customer ID, Transaction ID) → Purchase Amount: Each unique Transaction ID
determines exactly one Purchase Amount.

-Unique Column Combinations
-Inclusion Dependencies
